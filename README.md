# Lazy Loading & Firebase Deploy Demo

This demo project demonstrates **React Router lazy loading** with dynamic `import()` and deployment to **Firebase Hosting**.

### Overview
- **Framework:** React (Create React App)
- **Routing:** React Router v6
- **Features:**
  - Code splitting using `React.lazy()` and `Suspense`
  - Asynchronous route loaders for fetching data
  - Firebase Hosting configuration for SPA routing
